Проверка связи

Если не соединяется, нажмите кнопку у себя и попросите друга сделать то же самое. Пришлите оба результата.

    Настройки

    Свой TURN-сервер нужен, только если связь не устанавливается ни по коду, ни без сервера (строгий NAT, мобильный интернет). Укажите одинаково у обоих.

    Свой сервер соединения (PeerServer) — если общий сервер недоступен. Пустое поле — общий сервер. Укажите одинаково у обоих.

    Голос идёт напрямую между вами. Если сеть этого не пропускает, программа сама переключится на связь через сервер, голос при этом шифруется.
